2. 概述

Like Code 是一款本地代码编辑器，专注于 HTML 开发与预览。本应用的所有核心功能均在你的设备本地完成，不依赖外部服务器处理你的代码或个人信息。

3. 我们收集的数据

本应用不收集、传输或存储任何个人数据。

  • 不要求注册账号
  • 不收集姓名、邮箱、电话号码等个人身份信息
  • 不收集设备标识符或广告标识符（IDFA）
  • 不收集位置信息
  • 不集成广告 SDK 或第三方分析 SDK
  • 不使用 Cookie 或任何跟踪技术

4. 数据收集方式

由于本应用不收集个人数据，因此不存在主动或自动的数据收集行为。

5. 数据使用方式

由于本应用不收集个人数据，因此不存在将用户数据用于任何目的的情况。

6. 第三方开源组件

本应用使用以下开源软件组件，以上组件均在本地设备上运行，不涉及外部数据传输：

  • CodeMirror 6（MIT 许可证）— 代码编辑器引擎
  • Three.js（MIT 许可证）— 3D 渲染库
  • Babylon.js（Apache 许可证 2.0）— 3D 渲染库
  • Draco（Apache 许可证 2.0）— 3D 几何压缩

以上组件的代码在设备本地执行，不收集、不传输任何用户数据。

7. 代码执行与网络访问

  • HTML/CSS/JavaScript 代码在本地沙盒 WebView 中执行，无需网络连接。
  • 当你运行的代码中包含对外部资源的引用（如 CDN 链接、远程图片等），WebView 将通过你的网络连接加载这些资源。这些网络请求由你的代码主动发起，开发者不控制也不记录这些请求。
  • 你的代码内容不会发送到任何由开发者运营的服务器。

8. 文件管理与存储

  • 所有项目文件保存在应用沙盒目录内，仅在本地读写。
  • 支持通过拖拽操作导入文件，导入的内容仅写入本地项目目录。
  • 支持通过系统分享面板导出文件，相关内容仅在导出操作时传递给系统分享功能。
  • 应用卸载后，iOS 系统将自动清除应用沙盒内的所有数据。

9. 设备权限

为保障代码运行环境的完整性，本应用在系统配置中预声明了以下设备权限。这些权限仅在你编写的代码通过 WebView 主动调用相应功能时由系统触发请求，应用本身不会主动调用：

  • 相机
  • 麦克风
  • 语音识别

所有权限请求均会在使用时由系统弹出授权对话框，你可以选择"允许"或"拒绝"。拒绝授权不会影响应用的正常使用，仅相关代码功能无法执行。

本应用不申请、不使用以下权限：定位服务、通讯录、照片库、健康、Apple Pay、Siri。

你可以随时通过 系统设置 → 隐私与安全性 → 对应权限项 → Like Code 管理或撤销已授权的权限。

10. 数据保留与删除

  • 所有用户数据（项目文件、作品集、设置）仅存储在设备本地。
  • 你可以随时在应用内删除任何项目或文件。
  • 卸载应用将永久删除所有本地数据。
  • 由于本应用不在任何服务器上存储用户数据，因此无需服务器端数据删除流程。

12. 儿童隐私

2. Overview

Like Code is a local code editor focused on HTML development and preview. All core features of this application run locally on your device and do not rely on external servers to process your code or personal information.

3. Data We Collect

This application does not collect, transmit, or store any personal data.

  • No account registration required
  • No collection of names, emails, phone numbers, or other personal identification information
  • No collection of device identifiers or advertising identifiers (IDFA)
  • No collection of location information

Since this application does not collect personal data, there is no active or automatic data collection.

Since this application does not collect personal data, user data is not used for any purpose.

This application uses the following open source software components, all of which run locally on your device and do not involve external data transmission:

  • Babylon.js (Apache License 2.0) — 3D rendering library

7. Code Execution & Network Access

  • HTML/CSS/JavaScript code runs in a local sandboxed WebView. No network connection required.
  • When your code includes references to external resources (e.g. CDN links, remote images), the WebView will load these resources through your network connection. These network requests are initiated by your own code. The Developer does not control or log these requests.

  • All project files are stored within the app sandbox directory and are only read and written locally.

  • After uninstalling the app, iOS automatically clears all data within the app sandbox.

9. Device Permissions

To ensure the completeness of the code execution environment, this application pre-declares the following device permissions in its system configuration. These permissions are only triggered by the system when your code actively calls the corresponding functions through the WebView. The application itself does not actively invoke them:

  • Camera
  • Microphone
  • Speech Recognition

All permission requests will display an authorization dialog from the system at the time of use. You can choose "Allow" or "Deny". Denying permission does not affect normal app usage — only the relevant code functionality will be unavailable.

This application does not request or use the following permissions: Location Services, Contacts, Photo Library, Health, Apple Pay, Siri.

You can manage or revoke granted permissions at any time through System Settings → Privacy & Security → [Permission] → Like Code.

10. Data Retention & Deletion

  • All user data (project files, portfolio, settings) is stored locally on your device only.
  • You can delete any project or file within the app at any time.
  • Uninstalling the app permanently deletes all local data.
